# Chef's Menu Manager

React Native (Expo) app that lets a chef add and view menu items
(dish name, description, course, price).

## Run it

```
npm install
npx expo install expo react react-native @react-native-picker/picker
npx expo start
```

Scan the QR code with Expo Go, or press `a` (Android emulator) / `w` (web).

## Features
- Home, Add Menu Item and Menu List screens
- Text inputs, course Picker, FlatList display
- Validation with error messages, success confirmation, empty-list message
